1) Internet Kya Hai?
Internet ek global network of interconnected computers/devices hai jo ek doosre ke saath data communicate karte hain. Simple example:Internet ke through computers data exchange karte hain. Website bhi basically data communication ka ek form hai.



2) World Wide Web Kya Hai?
Yahan students aksar Internet aur Web ko same samajhte hain. Ye exactly same cheez nahi hain.
Internet: Global networking infrastructure.
Web: Internet par chalne wali service jahan websites/web pages access kiye jate hain.



-- University Question
Q1: Difference between Internet and World Wide Web?
Answer: Internet is the global network infrastructure that connects computers and devices, while the World Wide Web is a service running on the
Internet that allows users to access interconnected web pages and resources through web browsers.



3) Website Kya Hoti Hai?
Website basically related web pages/resources ka collection hoti hai jo usually ek domain ke under available hoti hai.
Example: example.com



4) Web Page Kya Hai?
Web page ek individual document/resource hota hai jo browser display karta hai. Example: index.html



5) Web Browser Kya Hai?
Browser wo software hai jo web resources ko retrieve karke user ko visual interface mein display karta hai.
Examples: Chrome, Firefox, Edge, Safari


6) Client Kya Hai?
Client wo device/software hota hai jo server se service/data request karta hai. Example: Tumhara Laptop + Chrome client side par hai.
Request: Client --> "Give me example.com"


7)  Server Kya Hai?
Server ek computer/system hota hai jo requests receive karta hai aur resources/data provide karta hai.
Example: Browser --> request --> Server --> response --> HTML
Server par website ki files ho sakti hain: index.html, style.css, script.js, images/

Client-server architecture mein client resources/services ke liye server ko request karta hai, aur server request process karke response provide karta hai.



8) HTTP Kya Hai?
HTTP = HyperText Transfer Protocol
Web communication mein HTTP commonly use hota hai.
Example: Browser --> HTTP Request --> Server --> HTTP Response --> Browser
:- Common HTTP methods: GET , POST , PUT , PATCH , DELETE



9) HTTPS kya hai?
HTTPS = HTTP Secure, HTTPS encrypted communication provide karta hai.
Website: http://example.com vs https://example.com
Modern websites ke liye HTTPS extremely important hai.


10) URL Kya Hai?
URL = Uniform Resource Locator
Example: https://example.com/products/cars?id=10
Isko parts mein dekho:
https:// → Protocol
example.com → Domain
/products/cars → Path
?id=10 → Query parameter


11) Domain Name kiya hai?
Human-friendly website address: google.com , github.com , youtube.com
Computer networking mein servers IP addresses ke through identify hote hain.
Domain users ke liye easy naming provide karta hai.



12) DNS kiya hai?
DNS = Domain Name System, DNS domain ko corresponding IP address se resolve karne mein help karta hai.
Concept: google.com --> DNS --> IP Address --> Google Server
Isay simple language mein internet ka phonebook-like naming system samajh sakte ho.


13) HTML Kya Hai?
HTML = HyperText Markup Language
HTML web documents ki structure aur semantic meaning define karne ke liye markup language hai. Important: HTML programming language nahi hai.


14) Markup Language Kya Hoti Hai?
HTML tags ke through document ke different parts ko identify karta hai.
Browser ko pata hai: <h1> → main heading, <p> → paragraph
Yahi markup ka fundamental idea hai.


15) HTML Element kia hai?
Example: <p>Hello World</p>
Ismein: <p> → Opening tag   |  Hello World → Content  |  </p> → Closing tag
Complete: Opening Tag + Content + Closing Tag = Element


16) Tag Kia hai ?
<p> ek HTML tag hai.
Examples: <h1> , <p> , <a> , <img> , <div> , <section>
Lekin ek important nuance: Har HTML element necessarily opening + closing tag nahi rakhta.
Example: <img> Image element ka normal HTML syntax closing tag require nahi karta.


17) Attribute kia hai?
Attributes HTML elements ko additional information dete hain.
Example: <a href="https://example.com">Visit</a>
Yahan href → attribute, "https://example.com" → attribute value
Another example: <img src="profile.jpg" alt="Profile photo">
Attributes: src , alt
