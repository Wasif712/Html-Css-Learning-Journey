# Questions Answers
Q1. What is Semantic HTML?
Semantic HTML uses meaningful elements whose names describe the purpose and structure of their content.
Q2. Purpose of <header>?
Page ya section ke introductory/header content ko represent karta hai.
Q3. What is <nav>?
Major navigation links ke section ko represent karta hai.
Q4. What is <main>?
Document ke primary content ko represent karta hai.
Q5. Difference between <section> and <article>?
section related thematic content ka group hai, jab ke article independently meaningful/self-contained content represent karta hai.
Q6. What is <aside>?
Main content se related but secondary content represent karta hai.
Q7. Purpose of <footer>?
Page ya section ki footer information represent karta hai.
Q8. Why is Semantic HTML important?
Improves structure, accessibility, maintainability, content understanding, and SEO-related page semantics.
Q9. Difference between <div> and <section>?
div generic container hai; section meaningful thematic section represent karta hai.
Q10. What are <details> and <summary>?
Interactive disclosure component banane ke liye use hote hain — summary visible label, details expandable content.
