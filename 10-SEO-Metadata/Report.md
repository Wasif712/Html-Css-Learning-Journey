# SEO kya hai?
Definition: Search Engine Optimization (SEO) is the practice of improving a website so that search engines can better understand, discover, and present its content to users.
Roman Urdu: SEO ka basic purpose ye hai ke search engines tumhari website ke content ko better understand aur discover kar saken.
Important: SEO sirf meta tags ka naam nahi hai.
Good:
Semantic HTML
+
Good content
+
Good page structure
+
Accessibility
+
Performance
+
Mobile friendliness
+
Technical SEO
sab mil kar important role play karte hain.

# <title>
Har important page ka meaningful title hona chahiye:
<title>Software Engineering Solutions | TechNova </title>
Title:
- browser tab mein show hota hai
- bookmarks mein use hota hai
- search engines ko page topic samajhne mein help karta hai

# Meta Description
<meta name="description" content="TechNova builds modern web applications, software systems and digital products for businesses.">
Ye page ka concise description provide karti hai.
Good practice
Description:
- relevant ho
- natural language ho
- page content ko accurately describe kare
Keyword stuffing nahi.

# Canonical URL
## Advanced SEO concept.
<link rel="canonical" href="https://example.com/services/">
Canonical URL search engines ko preferred URL identify karne mein help karta hai jab same/similar content multiple URLs se accessible ho.
⚠ Real project mein apni actual canonical URL use karni hoti hai; fake URL nahi.

# Open Graph
## Social sharing ke liye commonly used metadata.
Example:
<meta property="og:title" content="TechNova — Software Engineering Solutions">
<meta property="og:description" content="We build modern software products and digital experiences.">
<meta property="og:type" content="website">
<meta property="og:image" content="https://example.com/images/og-cover.jpg">
Jab URL social platforms par share hota hai, ye metadata preview information provide kar sakta hai.
