Q1: List Kya Hoti Hai?
Real world mein information aksar list ki form mein hoti hai.HTML mein lists isi information ko properly structure karne ke liye use hoti hain.

Q2: Unordered List <ul>
Jab order important nahi hota:
<ul>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ul>
Browser generally bullets show karega:
• HTML
• CSS
• JavaScript

Q3: <li> li ka matlab: List Item
Har individual item: <li>HTML</li>
Important rule: <li> normally <ul> ya <ol> ke andar use hota hai.

Q4: Ordered List <ol>
Jab sequence/order important ho:
<ol>
<li>Open VS Code</li>
<li>Create HTML file</li>
<li>Write code</li>
<li>Save file</li>
</ol>
Output concept:
1. Open VS Code
2. Create HTML file
3. Write code
4. Save file

Q5: <ul> vs <ol>
Element          Use
<ul>             Order important nahi
<ol>             Order/sequence important
<li>             Individual item
