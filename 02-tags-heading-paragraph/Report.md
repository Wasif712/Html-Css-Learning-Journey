Q1: Explain HTML heading elements?
HTML provides six heading elements from <h1> to <h6> . <h1> represents the highest-level heading and <h6> represents the lowestlevel heading. Headings provide a hierarchical structure to the content of a webpage.

Q2: <hr> — Horizontal Rule?
Content sections ke darmiyan thematic break:<hr> ka purpose sirf decorative line banana nahi; it represents a thematic separation.

Q3: <strong> — Important Text?
<strong> ka semantic meaning hai: This content has strong importance. Browser generally bold show karta hai.
Q: <b> vs <strong>?

Q4: <em> — Emphasis?
Browser generally italic show karta hai. <em> semantic emphasis provide karta hai. 
Q: <i> vs <em> ?

Q5: <mark> — Highlight?
Browser normally highlighted background show karega.Useful for: search results, important matching text, highlighted information

Q6: <sub> — Subscript?
Scientific formulas: H<sub>2</sub>O
Output concept: H₂O

Q7: <sup> — Superscript?
Mathematics: x<sup>2</sup>
Output: x²

Q8: <pre> — Preformatted Text?
Normally HTML whitespace collapse kar deta hai: <pre> whitespace/line breaks preserve karta hai.
<pre>
Name: Wasif
Role: Developer
Location: Pakistan
</pre>
Useful for: formatted text, ASCII diagrams, code-like content

Q9: <pre> + <code> ?
Code blocks ke liye common combination:
<pre>
<code>
git status
git add .
git commit -m "Update portfolio"
</code>
</pre>

Example:
